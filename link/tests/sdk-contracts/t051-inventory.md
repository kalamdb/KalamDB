## 2. Serialization Paths (`kalamdb-serialization`)

| Component | Source Path | Inspected Behavior | P0 / P1 Findings |
| --- | --- | --- | --- |
| Row & scalar value codec | `backend/crates/kalamdb-serialization/src/row/value.rs`, `row/decode.rs`, `row/batch.rs` | Encodes/decodes tagged ordinal values (`TAG_NULL`..`TAG_LIST`) and `RowView` (`FLAG_ROW_BODY_V2`). **P0 defects identified (`T064`):** (1) `decode_list` calls `Vec::with_capacity(len)` directly from untrusted `reader.u32()`; (2) `decode_embedding` calls `Vec::with_capacity(dimension as usize)` before checking negative/oversized dimensions against remaining bytes; (3) `skip_value` recurses on `TAG_STRUCT`/`TAG_LIST` without depth or work budgets; (4) `row/batch.rs::assert_nesting` runs post-decode, never increments `depth`, and checks outer `ListArray::len()` (always 1) instead of child element count. | Must be fixed in `T064` with parsing-time depth, element, work, and byte budgets before allocation. |
| Object & catalog envelope | `backend/crates/kalamdb-serialization/src/object/envelope.rs`, `object/generic.rs`, `model/` | Uses `KOBJ` magic header (`MAGIC = *b"KOBJ"`, `PROTOCOL_VERSION = 1`) wrapping FlexBuffers (`flexbuffers`) or MessagePack (`rmp-serde`) for catalog/system models. | `T069` extracts a lean core without mandatory Arrow/DataFusion/server dependencies; `T079`–`T081` converge owned persistence onto the selected current-epoch codec. |
| Function transfer helper | `backend/crates/kalamdb-serialization/src/function_value.rs` | Encodes `(contract_hash, serde_json::Value)` in FlexBuffers under `ObjectKind::Function`. | Replaced in `T056`/`T070` by direct typed domain-value encoding. |

## 3. Link, WASM, FRB, and Generated SDK Paths

| Component | Source Path | Inspected Behavior | Findings |
| --- | --- | --- | --- |
| Shared client transport & compression | `link/link-common/src/connection/websocket.rs`, `link/link-common/src/compression.rs` | WebSocket client supports JSON text and MessagePack (`rmp_serde`) binary frames, with gzip decompression. **P0 defect identified (`T065`):** `decompress_gzip` passes `usize::MAX` limit; `decompress_if_gzip` calls `decompress_gzip` and falls back to `Cow::Borrowed(data)` when decompression fails on gzip-prefixed bytes; `decompress_gzip_with_limit` tries zlib inflate then raw deflate without verifying gzip trailer CRC32/ISIZE modulo semantics or bounding compressed input size. | `T065` enforces finite input/output/expansion limits and removes silent failed-decode fallback; `T072`–`T078` remove MessagePack paths. |
| Browser/Node WASM bridge | `link/kalam-link-wasm/src/helpers.rs`, `wasm_client.rs` | Calls `compression::decompress_if_gzip(&raw)` on binary `ArrayBuffer` frames and uses `rmp_serde` when `SerializationType::MessagePack` is selected. | Must route through bounded decompression (`T065`) and shared Rust binary codec (`T074`). |
| Dart FRB bridge & SDKs | `link/kalam-link-dart/`, `link/sdks/dart/link/`, `link/sdks/dart/sync/` | Uses `flutter_rust_bridge` wrapping `link-common`. Slice 1 remote table builder (`KalamRemoteTable`) and `kalam_sync` single-Drift helpers exist. | Generated routines in `cli/src/workflow/schema/procedures.rs` currently emit `SELECT schema.fn($1)` / `CALL schema.proc($1)` SQL strings; `T054` switches generated routines to typed descriptor invocation. |
| Contract compiler & CLI codegen | `backend/crates/kalamdb-dialect/src/contracts/`, `cli/src/workflow/schema/` | `compile_contract` parses schemas, tables, composites, enums, domains, routines, topics, and triggers into `ContractSnapshot`. Currently omits composite primary keys, column default/identity/generated flags, routine parameter modes/defaults, `SETOF`/`RETURNS TABLE` cardinality, routine overloads, and per-entity scoped hashes in `ContractSnapshot`. | Addressed in `T003`, `T004`, `T005`. |

## 4. External Format & Transport Boundaries (Narrowly Exempt from Domain Codec Replacement)

| Boundary | Crate / Path | Format Role | Policy |
| --- | --- | --- | --- |
| PostgreSQL wire protocol | `backend/crates/kalamdb-postgres-wire`, `pg/` | External SQL client/FDW protocol (`pgwire`). | Product interface; not a KalamDB internal domain codec. |
| Cold storage segments | `backend/crates/kalamdb-filestore`, `backend/crates/kalamdb-flush` | Apache Parquet (`parquet`) and Arrow (`arrow`) columnar segments. | Ecosystem storage/analytics format; retained. |
| Key-value engine | `backend/crates/kalamdb-store` | RocksDB (`rocksdb`) SST/WAL container format; keys use `storekey`. | Engine container; KalamDB-owned row/catalog value payloads inside RocksDB use `kalamdb-serialization`. |
| Cluster gRPC transport | `backend/crates/kalamdb-raft` | Outer gRPC framing (`tonic` / `prost`) carrying Raft log/snapshot bytes (`kalamdb-serialization::protocol`). | Outer RPC transport may remain `tonic` while inner KalamDB domain payloads use `kalamdb-serialization`. |
| HTTP JSON / OpenAPI | `backend/crates/kalamdb-api` | Explicit external JSON representation (`serde_json`) for REST/SQL/OpenAPI. | External adapter only; never a mandatory intermediate tree for binary RPC/WS. |
