# v0.8.0

PostgreSQL session settings and catalog routines run on the shared SQL path used by HTTP `/api/sql` and the PostgreSQL wire protocol.

`SET`, `RESET`, `SHOW`, `current_setting`, and `set_config` apply to the connection session. Custom settings persist for the wire connection and for the HTTP request that set them. `SELECT schema.function(...)` from the catalog executes that routine before DataFusion looks for a table function.

Server, CLI, and SDK packages are 0.8.0. Internal SDK dependency ranges are `>=0.8.0 <0.9.0`.

## What's Changed

* Share PostgreSQL session settings and catalog routine calls across HTTP SQL and pgwire
