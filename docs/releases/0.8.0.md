# v0.8.0

One PostgreSQL grammar for HTTP SQL and the PostgreSQL wire protocol.

`psql`, HTTP `/api/sql`, and the wire listener compile through the same parser and executor. `SET`, `RESET`, `SHOW`, `current_setting`, and `set_config` apply to that session. A wire connection keeps custom settings until it closes. An HTTP request keeps them for that request. `SELECT schema.function(...)` runs the catalog routine before DataFusion looks for a table function.

Server, CLI, and SDK packages are 0.8.0. Internal SDK dependency ranges are `>=0.8.0 <0.9.0`.

This is a new storage, Raft, WebSocket, and SDK cohort. It is not an in-place upgrade of a 0.6 or 0.7.1 data directory. Use an empty data directory, or export and import into a fresh database. Startup does not delete the old directory. Old MessagePack WebSocket frames are rejected. JSON remains the text form.

### SQL

- `CREATE SCHEMA` is the schema statement. `CREATE NAMESPACE` remains an alias.
- `CREATE TABLE ... WITH (TYPE = 'USER'|'SHARED'|'STREAM')` is the table statement. `CREATE USER TABLE` is rejected. `CREATE USER` creates an identity.
- A table may omit a primary key. Storage assigns a hidden `_row_id`. `SELECT *` does not return it.
- Domains, composite types, enums, sequences, and table constraints use this SQL path.
- `search_path` resolves `"$user", public`. The stored schema key `default` is not merged with a schema named `public`.
- With the wire listener enabled, `pg_catalog` views project the system catalogs.

### Reads and writes

- Each primary key keeps one hot entry. The new version and the removal of the previous key land in the same write.
- An open transaction does not see commits that arrive after it starts.
- After a flush, `UPDATE ... WHERE id = <literal>` on a user table changes that row only.

### Clients

- Function calls, generated clients, and live WebSocket frames use the current binary frame.
- Ship the server, SDKs, and generated clients together. An older SDK is rejected rather than adapted.
- The PostgreSQL extension is built and published only when that option is selected on the release workflow.
